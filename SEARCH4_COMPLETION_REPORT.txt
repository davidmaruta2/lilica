11. CHEVRON ACTIVE/DISABLED LOGIC

Plain onLayout/onContentSizeChange/onScroll measurement (the same technique
this screen's own pre-existing `scrollToSection` already uses for the
vertical scroll) tracks container width, content width and current scroll
offset in refs, deriving `canScrollStripLeft`/`canScrollStripRight` booleans.

active in the middle. `accessibilityState.disabled` is set correctly
alongside the visual subdued/opacity treatment, and `disabled` genuinely
blocks the press handler (not just visually dimmed). Proven by 4 dedicated
tests covering the start state, the "more content -> right enables" case, and
scrolling away from/back to the start toggling the left chevron.
